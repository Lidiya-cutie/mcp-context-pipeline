**Модель по умолчанию:** glm-4.7 (Z.AI / Anthropic-compatible API)

---

## 1. Цели экспериментов

| Задача | Описание | Скрипт |
|--------|----------|--------|
| **DS-742** | Кросс-валидация ответов нескольких LLM: консенсус, оценка галлюцинаций | `src/cross_validation.py` |
| **DS-743** | Бенчмарк формулировок языковых инструкций (RU/EN/mixed, стили) | `src/instruction_benchmark.py` |
| **DS-744** | Автопоиск сжимающих инструкций с сохранением сущностей | `src/instruction_benchmark.py` |
| **DS-743 full** | Полный бенчмарк на 124 запросах, 3 языка (RU/EN/PL) | `src/full_benchmark.py` |

**Метрики:**
- **F1 / keyword_coverage** — сохранение ключевых сущностей и фактов
- **context_drift** — отклонение сжатого текста от исходника (порог ≤ 0.18)
- **compression_ratio** — степень сжатия
- **convergence_rate** — доля прогонов, прошедших пороги F1 и drift
- **avg_similarity** (DS-742) — попарное сходство ответов моделей
- **hallucination_risk** (DS-742) — доля расходящихся фрагментов

**Время:** 2026-07-01T14:33:07Z

## 6. Рекомендации для продакшена

1. **Инструкция по умолчанию:** `ru-descriptive` (пилот) или `en-descriptive` (full benchmark) — в зависимости от языка пользователя.
2. **Шаблон DS-744:** `auto-001` — «Сожми текст, сохранив сущности: имена, даты, числа».
3. **Кросс-валидация (DS-742):** использовать пару `glm-4.7` + `mimo-v2.5`; порог confidence < 0.9 → ручная проверка.
4. **PL-локаль:** для польских запросов предпочитать **EN-инструкцию**, не PL.
5. **OpenAI:** ключ `gpt-4o-mini` не работает (403) — исключить из пайплайна или обновить credentials.

---

## 7. Ограничения

- Пилотные DS-743/744 — только **5 синтетических кейсов** (tc1–tc5).
- DS-742 (glm+gpt) — **одна модель** из-за 403 на OpenAI.
- Full benchmark — одна модель (`glm-4.7`), без кросс-модельного сравнения.
- Latency PL-инструкций (14.7 с) может быть неприемлема для интерактивного UI.
